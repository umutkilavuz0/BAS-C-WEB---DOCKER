# 🚀 Full-Stack Web Application

Bu proje, modern web teknolojileri ve güvenlik standartları kullanılarak geliştirilmiş tam yığın (Full-Stack) bir uygulamadır.

## 🛠️ Teknolojiler

### Backend
* **Runtime:** Node.js
* **Framework:** Express.js (TypeScript)
* **ORM & Database:** Prisma ORM & PostgreSQL
* **Güvenlik & Auth:** JWT (JSON Web Tokens), Helmet, Express Rate Limit, CORS, Password Hashing

### Frontend
* **Framework / Bundler:** React & Vite (TypeScript)
* **State Management:** Zustand
* **Routing:** React Router DOM (Protected Routes / Korumalı Rotalar)
* **HTTP Client:** Axios (Interceptors desteği ile)
* **Styling:** Tailwind CSS
